# Guía de Contribución 🎓

¡Estamos encantados de que quieras ayudar a UniMySQL-MCP! Este es un proyecto educativo y todas las manos son bienvenidas.

## ¿Cómo puedes ayudar?
- **Reportando Bugs:** Si algo no funciona, abre un Issue.
- **Sugerencias:** ¿Tienes una idea para una nueva herramienta educativa? ¡Cuéntanos!
- **Código:** Si quieres arreglar algo o añadir una función, abre un Pull Request.

## Pasos para colaborar
1. Haz un Fork del proyecto.
2. Crea una rama para tu mejora (`git checkout -b feature/mi-mejora`).
3. Haz tus cambios y asegúrate de que el código sigue siendo "humano" y fácil de leer.
4. Abre el Pull Request.

¡Gracias por ser parte de la comunidad! 🚀
