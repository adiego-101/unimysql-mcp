# Política de Seguridad

## Reportando Vulnerabilidades
Si encuentras una vulnerabilidad de seguridad, por favor NO abras un issue público. Envía un correo a `adiego.portillo@gmail.com`.

Este proyecto está diseñado para entornos locales de aprendizaje. Nunca debe exponerse directamente a internet sin un túnel seguro o autenticación adicional.
